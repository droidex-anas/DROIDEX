These unmodified Latin variable WOFF2 subsets are embedded as data URLs so kits
compile and render offline. Each JSON carries the matching SIL OFL text, also
shipped in the executable kit as `fonts/<family>-OFL.txt`.

Sources (Fontsource 5.3.0):

- https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.3.0/files/inter-latin-wght-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource-variable/lora@5.3.0/files/lora-latin-wght-normal.woff2

Inter: Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter).
Lora: Copyright 2011 The Lora Project Authors (https://github.com/cyrealtype/Lora-Cyrillic).
Characters outside the Latin subset use the local system font stack.
