# DROIDEX wordmark

Fixed vector outlines from Silkscreen Regular, master m01, by Jason Kottke.
Source: https://github.com/googlefonts/silkscreen/blob/206ccf3f5234c281461e63ecc59cbc6b0563472b/sources/Silkscreen.glyphs
Source blob: 2d1301c6c8f429ac5999e54de786378bf5c3620f.

Uses the seven DROIDEX glyphs with the desktop's -0.04em letter spacing, preserving
original advance widths and optical offsets. This is wordmark artwork, not an
embedded font or a hand-drawn pixel alphabet. The app's BrandMark.swift renders
the same contours in native SwiftUI.
