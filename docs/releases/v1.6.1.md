## What's fixed

- **The Components tab is opaque again.** In a Design chat with a translucent sidebar theme, opening Components laid the frame list over the transcript with the messages showing through. The Design chat column now paints a solid sidebar tone, so the panel covers what is under it in every theme, light and dark.
- **One damaged saved design system no longer hides the rest.** If a saved kit's file could not be read, the design system picker showed "Design system metadata is damaged" and listed nothing, not even Auto or the presets. The picker now lists everything it can read, and the sidecar log names the file to restore or remove.
