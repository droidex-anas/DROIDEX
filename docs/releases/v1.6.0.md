## What's new

- **DROIDEX Design, now in beta.** Every new chat starts from one home with a Chat | Design switch. Pick Design, describe what you want, and the agent builds it as frames on a board beside the conversation. Design runs on your laptop with Droid, Claude Code or Codex, and the beta tag means the canvas format may still change.
- **A board you can work on.** Pan, zoom, fit and focus; frames keep numbered versions you can switch between; a compact toolbar sits on the frame you are looking at. Keyboard users get the same board: arrows move between marks, Enter edits, Delete removes, Escape leaves.
- **Say it on the frame.** Draw a mark or leave a note on any frame and send it with your next prompt. Pin a frame to talk about that one; the agent writes only to what you pinned. A docked Edit panel changes styles directly, with Delete and Undo.
- **Auto design system.** Design rests on Auto: the agent takes the style from your prompt, then from what is already on the canvas. DROIDEX, OpenAI-inspired and Claude-inspired ship as presets. Import your own from a `DESIGN.md`, CSS variables or a Tailwind config, and a frame remembers the kit it was built under.
- **Library.** Save a frame and it outlives its canvas, with its source, images and thumbnail. Start a new design from it, or pull it onto another board.
- **Fast and contained.** Frames compile in a worker and render in sandboxed previews behind a guard; at most four are live and none run while hidden. Frame work stays under 15 ms at p95 on an M4, with a flat heap across close and reopen.
- **Laptop-only, by design.** In the Remote browser the Design switch is hidden and a design chat says that designing is available on the laptop. Everything else in Remote works as before.
