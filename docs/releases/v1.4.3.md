## What's new

- **Scrolling up stays put.** Scroll up while the agent is writing and the chat stays where you are instead of pulling you back down. Once you're a screen or more above the latest output, a "Jump to latest" button takes you back in one click.
- **Replies stream in smoothly.** Text appears at a steady, even pace instead of in bursts.
- **Edits show what's happening.** While a file is being written, its row says "Editing", "Creating" or "Patching", then settles. Line counts change only the digits that move.
- **A cleaner "Worked for" fold.** Each finished turn's "Worked for 3m 39s" sits on a thin line above the answer, always shows its chevron, and brightens when you hover it.
- **Calmer rows.** Expand chevrons now sit after each row's label and appear on hover, so the transcript reads cleaner at rest.
- **Quieter thinking.** Expanded thinking is set in a softer tone so it recedes behind the answer, while staying readable in every theme.
- **The prompt rail fits narrow windows.** Its ticks are smaller and shrink to fit beside the transcript, hiding only when there's no room.

## Fixed

- **Loading placeholders line up with the chat.** The placeholders shown while a chat loads sit exactly where its content appears.
