## Fixed

- **Claude Code and Codex can be chosen again.** DROIDEX no longer greys out a harness because its CLI isn't signed in. The CLI handles its own sign-in and says so in the chat if it can't authenticate. Settings → Setup & updates shows whether each CLI is signed in.
- **Codex is found when the ChatGPT app has it.** If no other Codex CLI is installed, DROIDEX uses the one bundled with the ChatGPT app, which keeps it up to date.
- **Quitting during an update no longer breaks a CLI.** A Homebrew or npm update of Claude Code or Codex now finishes even if you quit DROIDEX while it runs.
