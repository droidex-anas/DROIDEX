## What's new

- **Devin is now in DROIDEX.** Pick the Devin harness in the model picker, next to Droid, Claude and Codex, and run Devin's models in the same app: SWE-2.1, SWE-2, SWE-2 Flash, SWE-1.7 and the Fusion pairs. Install the Devin CLI and run `devin auth login` once; DROIDEX finds your login.
- **Reasoning and costs for Devin models.** Choose a reasoning level for models that support one, and see each model's price in the picker.
- **Devin's own slash commands** show up in the composer.
- **Subagents, terminals and plans.** Devin's child sessions appear as subagents of the chat, its commands run in terminals the session owns and cleans up, and a plan it proposes comes to you as a review card.
- **Approvals that stay narrow.** "Always allow" covers the exact tool action you approved, and lowering the autonomy level takes effect immediately.
- **Copy a Devin chat.** Forking an idle Devin conversation starts the copy from its transcript.
- **Token usage for Devin sessions** is recorded and survives a resumed session.

## What's fixed

- **Devin signs in with logins on any Devin server.** DROIDEX now sends the login's server along with its key, so Devin no longer reports "Devin rejected the stored credential" for a valid login.
- **Devin terminals clean up after themselves**, including background processes they started, and Devin's pipes close when a session finishes.
