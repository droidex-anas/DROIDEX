## What's new

- **Setup starts from the agents you want.** First-run setup opens on a welcome screen, then walks three steps. Agents checks this Mac for Droid, Claude Code and Codex and lets you pick which to use. Set up installs each picked agent from the app, with a live log and Try again, and shows how to sign in. Defaults chooses the agent new chats start on, the editor files open in, and auto-updates. Nothing is saved until you finish or choose Set up later.
- **Design Mode.** Pick elements on a Design board and they become context for your next prompt, so you can point at exactly what to change. The agent is told which elements you picked, and you can ask for variants of a picked element.
- **Edit designs directly.** Select an element to edit its text, colours, spacing, effects such as blur and shadows, and SVG fill and stroke in the inspector, using your design system's tokens. Hold ⌥ to measure the distance between the selection and what is under the pointer. Undo covers the whole board.
- **Layers.** A Layers panel beside the board lists your frames and each frame's elements. Select from the list or the board, rename, hide and show, restack, drag or ⌥-arrow to move, duplicate and delete.
- **Vectors.** Paste an SVG on the board and it stays a vector frame. Edit a path's anchors and handles directly.
- **See the agent at work.** A frame the agent is writing shows its named cursor sooner, and when it finishes you can jump to what changed. One-click variants appear in a row below the source, with Use this variant.
- **Bring your own component library.** Import a project's shadcn/ui library as a design system. The kit lists its components with live previews and shows anything the import left out.
- **Components drawer.** The board's tool rail opens Layers (⌥1) and Components (⌥2) in one drawer. Each component shows a live thumbnail. Open one to see a larger preview, pick its variants, and choose **Add to board** to place it on the board as a frame of its own, beside the frame you are working on. ⌘Enter adds from the list, and one Undo takes it back.
- **Tag frames and components in the chat.** Tag a board frame or a kit component from its toolbar, with ⌘L, or with `@` in the composer, so the agent works from the real thing. A tagged component carries the variants you picked.
- **Export and images.** Start a frame from size presets such as poster and logo, export a frame as an image, or export it into the chat's project, where kit imports and tokens are rewritten to the project's own components.
- **Design system rules.** Choose how strictly the agent follows the design system: Off, Guide or Strict. In a chat with a project, DROIDEX offers to make a kit from it.
- **A smoother board.** Panning, zooming, dragging and resizing frames are smoother. The zoom bar is more compact, and it stays in place with the tool rail while you move around the board.

## What's fixed

- **Setup sees a newly installed agent.** An agent that finished installing or signing in while DROIDEX was checking could still read as missing. It now shows as ready.
- **Picking works under zoom.** Picking elements in Design Mode now lands on the right element when the app's UI is zoomed.
- **Skill prompts replay as typed.** A prompt that started from a skill now shows in the transcript as you typed it.
- **Inspector fields keep their values.** A field no longer jumps when you focus it, and the inspector says plainly when it cannot make an edit.
- **Menus keep their place.** The active row in a menu stays active when the pointer leaves it.
