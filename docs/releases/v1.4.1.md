## Fixed

- **Agents no longer die all at once with "Transport error: Droid process exited normally".** An agent running one of DROIDEX's own tools, such as a performance check, could start a second copy of the agent runtime on your profile, and that copy stopped every running chat, project lead and thread. Agents no longer see DROIDEX's private settings, a second runtime leaves the running one's agents alone, and only one DROIDEX opens per profile: launching it again brings the open window forward.
- **A chat whose Droid process stops comes back with your next message.** It used to fail with the same transport error on every send until the app was reopened. A turn that was running when the process stopped now ends instead of waiting forever.
- **Chats stay listed when a provider's transcript file goes missing**, for example after switching the Droid CLI's account. A damaged search index is set aside and rebuilt instead of hiding your history or stopping the app.
