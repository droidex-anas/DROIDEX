## What’s new

- Write prompts in a composer that renders markdown as you type: headings, emphasis, code, links, quotes, lists and tables style live, with a right-click formatting menu and Cmd+B/I/E shortcuts. Prompts and replies now share one renderer with consistent typography, scrolling tables, code cards and favicon link badges.
- Keep terminals across chat switches: each utility-pane terminal keeps its scrollback and rendering, busy shells confirm before closing, and exited shells offer a one-click restart. Processes the agent starts, such as dev servers, appear in a composer chip with their ports and can be stopped from there.
- Read tool activity as sentences (Read package.json, Searched src, Ran lsof) with live verbs, MCP source marks, and one shared terminal-style panel for arguments and results. File paths in tool rows, prompt chips and prose open the file in Review.
- Triage work faster in the sidebar: activity rows wear a status mark that settles a task on click, rows glide between groups instead of blinking, and pull request icons carry a check-status dot so a failing or running CI is visible at a glance.
- Steadier chrome: window controls follow the banner stack, panels open without relaying out the transcript, the copy control sits in the row gap, the model selector keeps long names and clickable effort dots, and app shortcuts can be rebound from Settings.
- The editor picker shows the real installed application icons, the Context panel scrolls and reads as plain text, error rows read like the other turn rows, and light themes get accessible status colours and contrast.
- A reusable icon library backs the app’s status and navigation icons, with a consistent spinner and reduced-motion support.

## Updating from 1.2.0

DROIDEX 1.3.0 keeps the existing application identity, Sparkle signing key,
architecture-specific update feeds, user-data location, session store, settings,
workspaces, automations store, and raw Factory session history unchanged.
Rebound shortcuts and sidebar view preferences are stored alongside existing
settings.

Update checks may run in the background, but DROIDEX does not download or
install updates automatically. Use **DROIDEX → Check for Updates…** or the blue
update button beside Settings, then approve the update and relaunch. The native
updater waits for the app and sidecar to settle before installing.

The macOS artifacts are ad-hoc signed, so a manual DMG install may require
approval in **System Settings → Privacy & Security** on first launch.
