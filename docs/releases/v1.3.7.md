## Fixed

- **Projects stay connected.** While a project was running, DROIDEX could show "The agent runtime sent a malformed event batch. Reconnecting with a fresh cursor." again and again. Each time, the Projects view missed its update, so **Resume** looked like it did nothing. Messages you sent could also be missing from the chat until you reopened it. Projects now update normally, Resume takes effect right away, and your messages show as soon as you send them.
