## What's new

- **Project chats read like a group chat.** Your messages stay as filled bubbles on the right. Each thread speaks from the left with its harness's icon and name first, in an outlined bubble, so a thread's report never looks like something you wrote. Long reports fold to a few lines with **Show more**, and a new report pops in as it arrives.
- **New project chats and threads are named after their title** instead of the instructions DROIDEX hands them.

## Fixed

- **One bad update no longer disconnects the app.** If the agent runtime sends something DROIDEX cannot read, only that one update is skipped; everything sent with it still shows, and there is no "malformed event batch" error or reconnect.
- **Droid's own notices are no longer shown as your messages.** "Unable to reach…", BYOK errors and usage switches now appear as a quiet note in the chat.
- Fixed a few more cases where a project, a project error or a Codex plugin could send DROIDEX something it would reject.
- The time under a short message no longer overlaps the next message.
