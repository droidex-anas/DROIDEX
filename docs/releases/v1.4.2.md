## What's new

- **The whole app now follows one design system.** Every surface — settings, sidebar, tabs, composer, transcript, dialogs, menus, side panes, automations and projects — is built from one set of tokens and shared components, documented in `docs/design-system/`. Surfaces separate with tone and space instead of lines, everything clickable shows a pointer cursor, and a lint rule keeps new UI on the system.
- **Light mode is as readable as dark mode.** Hover and selected states are clearly visible, and the contrast is checked by a test.
- **Long chats get a prompt rail.** Each prompt is a tiny tick beside the transcript; hovering swells the ticks under the pointer like piano keys and shows the prompt with a snippet of its reply. Click or use the keyboard to jump, even hundreds of prompts back.
- **Inline code reads cleanly.** Code spans sit tight against the text around them, selecting across them is one continuous band, and copying code keeps its blank lines exactly. Markdown files open in Files with rich rendering — headings, tables, highlighted code in every supported language — and images fit the pane without flashes or jumps.

## Fixed

- **Restarting DROIDEX restores where you were.** The app reopens on the session, view and scroll position you left, and the folders you revealed in the sidebar stay revealed.
- **The Credits row is gone from Settings.** The agent cursor's icon credit moved to the NOTICE file, where the licence wants it.
