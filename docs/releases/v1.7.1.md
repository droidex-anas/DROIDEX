## What's new

- **Quitting asks first while agents are working.** Quit DROIDEX while an agent is still working and it asks before stopping it, for example "2 agents are still working". Cancel keeps everything running. Quit waits a few seconds at most for the agent runtime to save chat history before the app closes.
- **Closing the last window lets agents finish.** On macOS, closing the last window no longer stops agents that are still working. DROIDEX stops the agent runtime once nothing is working.
- **Chats are named from what you asked.** A new chat takes its name from the first sentence of its opening message, cut between words. Markdown never becomes the name: `1. Fix the login bug` names the chat "Fix the login bug". When Droid writes its own title after the first turn, the chat takes it, unless you renamed the chat yourself. A new name writes itself in from left to right.
- **Sidebar rows glide.** When a chat moves up the list or is pinned, its row glides to its new place and the rows around it close the gap. A new chat fades in. Forks that keep their source's name show a muted "fork 1", "fork 2", in the order they were made.
- **The chat title sits on the content edge.** The title loses its pill and drag grip, uses the whole row, and shimmers only while the agent is working, not while it waits for your answer.

## What's fixed

- **History saves after a hard shutdown.** If the Mac turned off while DROIDEX was running, the next launch could refuse to save chat history and warn that the previous agent runtime exited with unflushed history. A lock left from before the restart now counts as released, for chat history and for Design canvases.
- **Restored subagents read as paused.** A subagent that was still running or waiting when DROIDEX closed now opens as paused, instead of staying pending with nothing behind it.
