## What's new

- **A pull request workspace.** The Pull Requests tab is now a full-canvas board with workflow grouping, quick filters, sorting, keyboard navigation and queue stepping.
- **Review changes in DROIDEX.** Pull requests open into Summary and Changes views with a file tree, unified or split diffs, reviewed-file checkboxes and inline review comments.
- **Send review notes to Droid.** Notes anchor to exact diff lines and can be sent as a Droid prompt with their file, line and code context.
- **Pull requests beside the chat.** GitHub pull request links open in a compact side pane, where Chat, Review with Droid and Send review target the chat they came from.

## What's fixed

- **Settled transcript rows no longer shimmer** after a turn finishes.
- **Execution liveness stays with its active generation**, so superseded work cannot keep a chat looking alive.
- **Questions sit in the composer surface**, keeping the prompt where you answer it.
