# Proposed icons

Sixteen new icons for review: a soft folder family and wider, rounded cursors for computer use. They aren't in `packages/icons` yet, and they sit alongside the existing icons rather than replacing them.

- **Same grammar as the set:** 24px grid, 1.5px stroke, round caps and joins, about 3.5px of optical padding, and filled variants that fill the same outline.
- **Folders** use the file icon's soft, continuous corners instead of the old folder's tight arcs, and their tab eases into the body. The family is `folder`, `folder-filled`, `folder-open`, `folder-open-filled`, `folder-plus`, `folder-minus`, `folder-search`, `folder-git`, `folder-code`, `folder-cursor` (a workspace being driven by computer use) and `folders` (projects).
- **Cursors** are a wider pointer with fully rounded corners and a soft notch at the tail. The tip angle is about 55° instead of the old 49°. There are three weights: `cursor` (outline), `cursor-filled` and `cursor-duo` (30% fill with an outline). There are also two actions: `cursor-click` and `cursor-select`. The old `mouse-pointer` and `computer-use` icons stay.
- In the Context panel, use `folder` for the workspace row and `folder-cursor` wherever a workspace is under computer use.
