08 / Toasts

Quiet notices

A raised card where colour lives only in the small status icon, with no dots, side bars or tinted backgrounds. Fire a few and they stack in the corner. Hover the stack to fan it out and pause every timer. Errors and updates stay until you dismiss them.

Timing: success and info 4s (6s with an action), warning 6s, error, update and loading stay. The same notice raised twice counts up (×2) instead of stacking. Loading turns into success in place, with the icon cross-fading. Swipe isn't shown here; Escape dismisses the newest.

10 / Rules

The ten rules

The short version of the rulebook. Anyone building DROIDEX UI, person or agent, checks a screen against these before it ships.

  1. Only tokens

    No hex values, no [13.5px], no one-off radii.

  2. Eleven type styles

    If text needs to look different, it's a different style, not a tweak.

  3. Three weights

    400 to read, 500 to click, 600 for headings.

  4. Borders only where necessary

    Tone, space and floating shadow. Only the meaningful lines in rule 4; no header, footer or group hairlines.

  5. Colour is a signal

    Links, status, consequential actions, the brand mark.

  6. One primary per surface

    Everything else is secondary or ghost.

  7. Radius grows with size

    8 → 12 → 16 → 24.

  8. Every state

    Rest, hover, pressed, focus, disabled, loading, empty, error.

  9. Nothing jumps

    Reserve space, use tabular figures, reserve the scrollbar gutter.

  10. Keyboard first

    Focus is visible only for the keyboard, and Escape always backs out.

11 / Next

What adds taste from here

Once the system is in the code, these are the next layers of polish. Each one is small on its own, but together they make the app feel crafted.

Empty states with a voice

Every empty list gets one line saying what will appear here and one action to start, centred, with a 20px icon in text-muted.

Keyboard everywhere

A command palette for every action, shortcuts shown in menus, and arrow-key navigation in every list.

Optimistic everything

Rename, pin and archive change instantly and quietly undo if they fail. No spinners on things that almost always work.

Context menus

Right-click on any row gives the same actions as its more-actions button, so hover is never the only way in.

Considered loading

Nothing for 300ms, a shaped skeleton until 2s, then words. Streaming text grows in place.

One sound of the brand

The orange X appears in exactly one live place, the update and welcome moments, so it stays special.
